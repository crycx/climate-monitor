Climate Monitor Setup

ESP32-C3 (WiFi sensor, ESP-NOW sensor or gateway), ESP32-C6 gateway or XIAO ESP32C6 battery sensor over USB; the page shows the fields for the connected device. Use Chrome or Edge on a desktop. Close espflash monitor first, since only one program can open the port.

Not connected

The device does not deep-sleep while a computer is attached. If it was asleep (battery sensor), press RESET first: its console only starts on a fresh boot.

Saving does not restart the sensor. Unplugging USB continues the normal battery cycle.

Transport

Readings go over WiFi to the backend and MQTT. No WiFi connection: readings go to the ESP-NOW gateway, which forwards them to Home Assistant. WiFi mode, and also receives ESP-NOW sensors and forwards them to MQTT and the backend.

Measurement

A gateway must stay awake to receive sensors: turn deep sleep off.
