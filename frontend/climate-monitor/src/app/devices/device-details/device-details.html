Configuration Guide
  1. Enter the device name and type, generate or paste the API key, then click {{ isCreateMode ? 'Create' : 'Save' }}.
  2. Power on the device and wait for first boot. If it connects to Wi-Fi automatically, continue using normal operation.
  3. If AP Wi-Fi (ClimateMonitor-xxxxxxxxxxxx) does not come up, press the AP button on the device (short press). If needed, hold it for about 3 seconds to force AP mode. Connect your phone or laptop to the AP network named ClimateMonitor-xxxxxxxxxxxx (the suffix is the device MAC in hex).
  4. Open http://192.168.4.1/ in a browser. Fill in Wi-Fi SSID and password.
  5. Add or update API Key. Set or correct the Endpoint URL only if needed
    default: https://climate.sinpal.ee/api/. You can also change the measurement interval there if needed.
  6. Save the configuration and wait for reconnect. LED behavior: slow blinking means AP portal is active, solid ON means data is being sent, OFF means idle.
